Commits

                        
The Commits tab shows a unified commit graph across local branches, remote branches, and tags.
                            Click a ref chip on a commit (or a branch in the left column) to check it out, compare it, merge it,
                            create a branch/tag from it, or rebase onto it. Selecting a commit shows its diff on the right;
                            switch to the "Tree" tab there to browse the repository contents at that revision, with an
                            optional Blame view per file.


                        
Branches

                        
Click the branch name in the toolbar to list every local and remote branch side by side, with
                            ahead/behind counts and a filter box to find one quickly. Click any branch there to check it
                            out, merge or rebase it, create a branch/tag from it, or delete it.


                        
Changes

                        
The Changes tab lists your Working Copy and Staging Area separately. Select files and use
                            Stage / Cancel / Unstage, or select individual lines in the diff for finer-grained staging.
                            Stash or discard changes from the toolbar above the list, then enter a message and commit.


                        
Search

                        
The Search button (or Ctrl+F) opens an overlay that filters the current commit or branch list
                            as you type.


                        
Repo menu

                        
Click the repo name to open, clone, or create repositories, switch between recent ones, or
                            browse a folder of repos at once. The same menu also gives access to worktrees, stashes,
                            the reflog, and submodules.
